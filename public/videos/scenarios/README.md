# Perspective X Cinematic Video Assets

Place your generated AI videos in this folder. The application is configured to search for these files dynamically. If a video is found, it will play. If it's missing, the app will fall back to the interactive slide mode.

## File Naming Convention
Each video must be named exactly after its corresponding **Scenario ID** and have the `.mp4` extension.

Here is the exact list of files you should place in this directory:

1. **Water Contamination** ➔ `water_contamination.mp4`
2. **Desert Air Quality** ➔ `acid_rain.mp4`
3. **Mangrove Preservation** ➔ `invasive_species.mp4`
4. **Runaway Reaction** ➔ `reaction_gone_wrong.mp4`
5. **Gas Law Boyle** ➔ `gas_boyle_adnoc.mp4`
6. **Gas Law Charles** ➔ `gas_charles_aviation.mp4`
7. **Gas Law Gay-Lussac** ➔ `gas_gaylussac_cylinder.mp4`
8. **Genetic Counseling** ➔ `mutation_dilemma.mp4`
9. **Athlete Performance** ➔ `reaction_time.mp4`
10. **Space Chemistry** ➔ `oxygen_failure.mp4`
11. **Mountain Hazards** ➔ `unstable_slope.mp4`
12. **Grid Load Management** ➔ `power_grid.mp4`
13. **Sustainability** ➔ `heat_loss.mp4`
14. **Medicine Quality** ➔ `aspirin_production.mp4`
15. **Stoichiometric Yield** ➔ `aspirin_percent_yield.mp4`
16. **Green Fuel Stoichiometry** ➔ `fuelproduction.mp4`

## Format Guidelines
- **Format**: MP4
- **Aspect Ratio**: 16:9 (recommended widescreen)
- **Resolution**: 1080p (recommended for web performance) or 720p
- **Audio**: Include the voiceover/narration and background music mixed into the video file itself.
