This package contains 217 separate English voice-script files, organized by speaker.

## Important
These are production-ready text inputs for ElevenLabs, not rendered MP3 audio. Rendering requires the selected ElevenLabs Voice ID for each character and access to an ElevenLabs account/API.

## Recommended workflow
1. Assign one fixed ElevenLabs Voice ID to each speaker.
2. Import each TXT file separately.
3. Export as MP3, 44.1 kHz, 128–192 kbps, or WAV, 48 kHz, 24-bit for final mastering.
4. Preserve the file-name stem when exporting so the website can map audio clips to scenes.
5. Use manifest.csv for scene, speaker, direction, and text mapping.
